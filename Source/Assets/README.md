# Иконки категорий

- ScreenXpert — контур двух лент, перерисованный по [официальной PNG Microsoft Store](https://store-images.s-microsoft.com/image/apps.56032.14032635365210999.1f064ff7-5378-41d8-8c16-6efa4e2b048f.81d0bc4a-e865-4452-ba0a-e09add571b6c), логотип ASUSTeK COMPUTER INC. Синяя плитка и цветные заливки не используются.
- Wallpaper Engine — готовый контурный [SVG Arcticons](https://github.com/Arcticons-Team/Arcticons/blob/0ad65f34bf60959a3cc97e31a0f033c1084cea51/icons/white/wallpaperengine.svg).
- Armoury Crate — предоставленный пользователем SVG логотипа ASUSTeK COMPUTER INC., сохранённый как armoury_crate.svg. Исходные белые составные контуры сохранены без дополнительной обводки. Исходное поле SVG 48×48, размер в приложении 20×20 DIP. Фон удалён, SVG не содержит встроенного растра.

Исходные SVG сохранены в Category. Иконка Wallpaper Engine: Arcticons Team, Donnnno и участники проекта, CC BY-SA 4.0. Полные условия находятся в Category/CC-BY-SA-4.0.txt; адаптация этой иконки остаётся под той же лицензией. SVG Armoury Crate предоставлен пользователем отдельно от Arcticons. Источники и изменения всех иконок указаны в Category/NOTICE.txt. Имена, логотипы и товарные знаки принадлежат соответствующим владельцам.

GenerateCategoryIcons.ps1 преобразует SVG в CategoryIcons.xaml при сборке. Для обеих SVG сохраняется геометрия и масштаб 48→20 DIP. У Wallpaper Engine применяется обводка 1,3 DIP; у Armoury Crate сохраняется исходная заливка составных контуров с правилом nonzero. CategoryIcons, уведомление об авторстве и лицензия Wallpaper Engine встраиваются в конструктор; краткая атрибуция доступна в свойствах EXE, поле комментария. Для показа категорий программа не обращается к интернету или каталогам установленных приложений, не читает внешние SVG и не распаковывает изображения. Icon0–Icon4.ico — отдельные иконки конструктора и создаваемых режимов.
