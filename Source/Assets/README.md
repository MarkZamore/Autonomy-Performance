# Иконки категорий

- ScreenXpert — два диагональных контура ленты.
- Wallpaper Engine — смещённые рамки с шестерёнкой.
- ARMOURY CRATE — шестигранник с треугольными гранями.

Контурные векторные рисунки находятся в Source/CategoryIcons.xaml и встраиваются одним ресурсом CategoryIcons. Размер 20×20 DIP и белый контур 1,3 DIP согласованы с остальными значками категорий. Прежние растровые файлы удалены. Для показа категорий программа не обращается к каталогам установленных приложений или временным файлам пользователя. Icon0–Icon4.ico — отдельные иконки конструктора и создаваемых режимов.
