# Иконки категорий

- ScreenXpert.png — ресурс установленного пакета ScreenPadMaster/ScreenXpert, 256×256.
- WallpaperEngine.ico — иконка приложения из локальной библиотеки Steam; содержит несколько размеров.
- ArmouryCrate.png — предоставленный пользователем снимок значка. Интерфейс показывает только область логотипа через CroppedBitmap, без подписи страницы.

Эти ресурсы встраиваются при сборке. Для показа категорий программа не обращается к каталогам установленных приложений или временным файлам пользователя. Icon0–Icon4.ico — отдельные иконки конструктора и создаваемых режимов.
