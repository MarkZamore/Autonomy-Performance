# Autonomy&Performance

Портативный конструктор Windows 11 x64: WPF/.NET Framework 4.8, один EXE. Экспорт копирует встроенный winexe-исполнитель и редактирует ресурсы PE в памяти; компилятор на компьютере пользователя не нужен. Версия конструктора - порядковый номер коммита. У созданных режимов ресурс версии удалён.

## Настройки и предпросмотр

Слева шесть свёрнутых категорий: ScreenXpert, Wallpaper Engine, ARMOURY CRATE, «Режим питания Windows», «Дисплей», «Дополнительно». Энергосбережение - первый пункт режима питания. ScreenXpert начинается с бережной зарядки, затем три режима вентиляторов. ARMOURY CRATE пока пуст.

Режимы питания/вентиляторов взаимоисключающие, повторный щелчок снимает выбор. Обычные тумблеры: выключить / не менять / включить. «Исправление панели задач»: не менять / режим 1 / режим 2. Тумблеры плавно перемещаются и меняют оба цвета за 120 мс; выключенные цвета включённого состояния поменяны местами. Нумерации и принудительного межстрочного интервала в предпросмотре нет; действия разделены пустой строкой.

Пресеты полностью заменяют действия, включая новые пункты и настройки экрана, но сохраняют выбранную иконку. Пресет не применяет параметры и не сохраняет файл. После сохранения кнопка недоступна до изменения конфигурации/иконки. Успешное сохранение не показывает статус. Подсказки - только у выбора иконки и пяти встроенных вариантов.

## Экран и датчики

EnumDisplayDevices/EnumDisplaySettings перечисляют активные однозначно определённые экраны и режимы драйвера с текущей глубиной цвета, ориентацией и флагами. Разрешения и частоты берутся из этих режимов; частота зависит от выбранного разрешения. ChangeDisplaySettingsEx сначала проверяет сочетание, затем применяет и перечитывает его. При изменении только разрешения текущая частота сохраняется, если допустима; иначе частоту выбирает драйвер. Пользовательские тайминги не создаются.

Масштаб - дискретный список из CCD GET=-3, SET=-4 относительно рекомендованного Windows значения. Неподдерживаемые данные пропускаются. HDR - публичные CCD-пакеты с проверкой версии Windows и возможностей выбранного target. DRR использует виртуальные режимы CCD и DISPLAYCONFIG_PATH_BOOST_REFRESH_RATE: проверяет топологию через SDC_VALIDATE, не применяя её при открытии конструктора. Возможность зависит от текущего физического режима: необходим поддерживаемый встроенный экран с высокой частотой. Неподдерживаемый/непроверенный режим блокируется. При выполнении все возможности проверяются заново.

Отключённый, исчезнувший или неоднозначный дисплей не заменяется другим: его разрешение, частота, масштаб, HDR, DRR и оптимизация яркости пропускаются. Яркость задаётся отдельно через WMI активным совместимым панелям. Солнце включает действие, перечёркнутое солнце отключает; смена значка анимируется.

Под яркостью - автояркость по освещению и список CABC: не менять / откл. / всегда / только от батареи. Для автояркости проверяется Windows LightSensor и доступная аппаратная яркость. Присутствие, взгляд, пробуждение и посторонние взгляды проверяются раздельно через HumanPresenceFeatures и дополнительные интерфейсы WinRT. При отсутствии функции контроль приглушён, выбор очищается и не экспортируется. Windows может дополнительно запретить изменение HumanPresenceSettings непривилегированному приложению; исполнитель пропускает отказ без повышения прав.

Ночной свет глобален для Windows, а не отдельного монитора. Интенсивность 0-100 соответствует 6500-1200 K линейно. Ползунок доступен только при «Вкл.». Изменяется распознанная структура CloudStore CompactBinary v1, с сохранением расписания/неизвестных полей и обновлением timestamp; незнакомый формат пропускается. Это внутренний механизм, совместимость с будущими сборками не гарантируется.

## ASUS, Wallpaper Engine и панель задач

Бережная зарядка использует тот же WM_COPYDATA-канал, что установленный ScreenXpert: ASUSSCREENXPERTUI, функция 700, BatteryCareMode=80/100; поддерживаемый интеллектуальный вариант - 256. Проверяются capability, получатель и прочитанный ChargingRate. Режим временной полной зарядки не перезаписывается. Вентиляторы используют тихий ASUS HCONTROL, стандартный профиль конфигурации 3 преобразуется в нативный 0, а не FullSpeed. Невыбранные пользовательские режимы AC/DC сохраняются после возможной синхронизации ASUS.

Wallpaper Engine: независимые play/pause и mute/unmute; громкость Windows не меняется. Без запуска приложения эти действия пропускаются. Отдельное действие запуска находит установку на целевой машине (реестр Steam/библиотеки), проверяет продукт и запускает wallpaper64/32.exe -silent напрямую. Завершение отправляет WM_QUIT потоку WPEEventWindow и ждёт штатного выхода, без Kill/Steam/launcher.exe. Повторный запуск/выход безопасен. При выбранном запуске приложение стартует до команд звука/воспроизведения; при завершении закрывается после них.

Исправление панели задач записывает MMTaskbarMode=0, синхронно уведомляет Shell_TrayWnd через WM_SETTINGCHANGE/TraySettings, затем устанавливает 1 (главная+экран окна) или 2 (экран окна). Explorer не перезапускается. Незавершённая последовательность откатывает исходный параметр. Отдельные действия IsBatteryPercentageEnabled и ShowSecondsInSystemClock меняют собственные параметры Windows и уведомляют оболочку.

## Портативность

Конструктор не хранит пользовательские настройки/историю, не создаёт свои ключи, службы, задания или ассоциации. При сохранении используется один временный файл только в выбранной папке с удалением при завершении/ошибке. Обычный исполнитель не пишет отчётов или вспомогательных файлов; выбранные системные параметры могут сохраняться Windows/ASUS в реестре и собственных хранилищах. Абсолютного отсутствия системных следов не обещаем. Mutex и ограниченное ожидание защищают последовательные запуски.

Строка износа читается через Windows.Devices.Power.Battery.AggregateBattery.GetReport: FullChargeCapacity/DesignCapacity в mWh переводятся в Wh; износ = max(0, 1-full/design)*100. Формат - три знака ёмкости и один знак процента, десятичная точка. Неизвестные значения отображаются как «нет данных». Файл batteryreport, кэш, опрос по таймеру и фоновые службы не создаются.
