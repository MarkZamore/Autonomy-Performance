# Изменения

## 30

- Исправлены процент заряда батареи и секунды часов: оба действия используют действующий брокер параметров Windows для текущего пользователя вместо неработающей записи реестра с уведомлением панели задач.
- До применения проверяются доступность и политика, после него перечитывается действующее значение. Недоступные действия приглушаются в конструкторе и пропускаются экспортированным EXE без UAC и дополнительных окон.
- Новый механизм встроен в конструктор и общий шаблон всех экспортов. Старые скрипты с этими действиями нужно пересохранить.
- Ночной свет переведён с редактирования CloudStore на брокер Windows с прямой интенсивностью 0-100 и проверкой действующего результата. Интенсивность проверяется до включения режима; выключение не меняет её. Параметры расписания напрямую не редактируются, снимок ограничен текущим ручным режимом и интенсивностью.
- Конструктор и экспортированные EXE показывают один номер выпуска N в FileVersion и ProductVersion. Экспорт сохраняет VERSIONINFO, техническая AssemblyVersion остаётся 1.0.N.0.
